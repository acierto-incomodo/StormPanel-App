Documentación de StormPanel

Requisitos e instrucciones para instalar StormPanel App.

Requisitos del sistema

Para utilizar StormPanel App, necesitas cumplir con estos requisitos:

  • Sistema operativo: Windows 10 o superior.
  • Procesador: Intel Core i3 o Ryzen 3, o superior.
  • Memoria RAM: 0,5 GB.
  • Almacenamiento: 500 MB de espacio libre.

Instalación

Descarga el instalador de StormGamesStudios | StormPanel App desde la página de versiones de GitHub y ejecútalo para instalar la aplicación.
